# 🌐 Viran Portfolio

A modern responsive developer portfolio built using **Flask, HTML, CSS, and JavaScript** with a strong focus on clean UI, responsive layouts, smooth user experience, and backend integration.

This portfolio reflects my journey from frontend development toward backend engineering and AI/ML learning.

---

# ✨ Features

- Modern responsive UI
- Flask-powered portfolio structure
- Mobile-first responsive design
- Modern hero section
- Rebuilt animated navbar
- Dynamic skills section
- Project showcase cards
- Contact form with email integration
- Glassmorphism inspired UI
- Smooth hover effects & transitions
- Organized component-based templates
- Environment variable security using `.env`
- Ready for Render deployment

# 📧 Contact Form System

The portfolio includes an email-based contact system using EmialJS.

When someone submits the contact form:
- The message is sent directly to your email
- No database is required
- Secure credentials are stored using environment variables
